# OpenHexa — Landing

Page d'accueil du projet [OpenHexa](https://github.com/OpenHexa-fr) : présente
l'écosystème, son objectif, et redirige vers chaque produit ([Immo](https://immo.openhexa.fr),
[Essence](https://essence.openhexa.fr)).

Site statique Next.js, sans backend ni base de données — pas de variables
d'environnement nécessaires.

## Développement local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
